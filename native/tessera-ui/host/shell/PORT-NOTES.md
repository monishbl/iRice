## Unowned (resolved at integration)
Every call this crate makes now has an owner. Added here for the others: `launch.terminal [[argv], hold]`, `launch.run [[argv]]`, `tools.recheck` (no-op), `uistate.set [key, value]`, `shellpriority.set` (= priority.set), `backends.fix|startNm|openWifiApp|fixBluetooth`, `needs.turnOnAvahi`, `bugreport.set|editShot|openGithub` (the report is built from the fields kept here when `send|copy|github` get no object), `welcome.request` (= open), picker reply `share` (Panels.pickShare -> `panels.share`), shortcuts `emoji`, `switcher`, `switcherBack`, `switcherCommit`, `captions`. Changed to the owners' names: `input.nextLayout` -> `keyboardlayout.next`, `share.pick` -> `picker.pick` (reply `share`). The settings router now calls host-system's bridges by their documented names (`devices.act`, `input.act`, `accounts`, `about.<what>`, `system.<what>`) and tells them `<group>.live [open]` and `<group>.page [id]` as the Settings window opens, closes and changes page. `island`: `act` on an alert of host-desktop (uid >= 1_000_000_000) is forwarded to `today.islandAct "<uid> <which>"`; `alertAct`, `forget`, `clear` for Notification Center's alert rows; `post` also takes `{event, ms}`, `remove` also `{key}`, `more[]` items may carry `call`/`args` directly. `sound.notify` takes the notification object itself.
