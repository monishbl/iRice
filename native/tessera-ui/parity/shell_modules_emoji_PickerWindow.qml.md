# shell/modules/emoji/PickerWindow.qml → surfaces/emoji (ui/emoji.slint, src/lib.rs, src/view.rs)

Spring conversion (Qt SpringAnimation steps 16 ms): ω = √(62.5·spring), ζ = 62.5·damping / (2ω); Slint `spring(bounce)` with duration d: d = 2π/ω, bounce = 1 − ζ.
Open: Theme.motion.spring + 0.8 / damping + 0.06 → Material 6.88 / 0.56: ω 20.7, ζ 0.84 → 303 ms spring(0.16); Glass (motion "subtle") 4.6 / 0.38: ω 17.0, ζ 0.70 → 370 ms spring(0.3).
springFast 12.8 / 0.54 → 222 ms spring(0.4). springPress 7.5 / 0.3 → ω 21.7, ζ 0.43 → 290 ms spring(0.57).
