Report a bug

Something not working? Tell us from iRice itself: it attaches what's needed to fix it, and you see all of it before it's sent.

Open Settings → Report a Bug, search Spotlight for Report a Bug, or bind the Report a bug action to a shortcut or trackpad gesture. Starting it from Spotlight or a shortcut takes a screenshot of the screen as it was.

What a report sends

Only what you leave switched on:

  • Your description: the title, what happened, the steps and what you expected.
  • A screenshot, which you can mark up first to hide anything private.
  • The last 500 lines of iRice's log.
  • System info: the iRice, Hyprland and Quickshell versions, your graphics, displays and distribution. Not your computer's name or your user name.

Before anything is sent, iRice takes out of the log and system info: your home folder, user and computer names, email addresses, anything that looks like a password, key or token, IP and MAC addresses, and the names of your Wi-Fi networks and Bluetooth devices. The page shows you the result.

Where it goes

Reports become public issues on iRice's GitHub, so don't write anything private in them. A copy is kept by iRice's report server so the screenshot can be linked from the issue.

Your IP address is used only to allow a few reports an hour from one network. It isn't stored: the server keeps a scrambled, salted value for an hour's count and deletes it after a day.

Can't send it from iRice?

If the report server can't be reached, the page offers Copy report and Open on GitHub. You can also open an issue directly.
