iRice settings to try

  config.json   the settings: glass material, colours and contrast, menu bar,
                dock, Control Center, cool-down and the rest. No personal
                data, keys or desktop widget layout. The wallpaper stays
                iRice's own.
  import.sh     applies them.

Installed iRice:                         ./import.sh
iRice run from a folder (./dev.sh tty):  ./import.sh --repo ~/iRice

Your current settings are backed up first (config.json.before-import-<date>,
next to config.json), and your desktop widgets stay as they are.
